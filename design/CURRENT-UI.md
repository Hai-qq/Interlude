# 当前交互与窗口

主小窗、提醒、休息与归来为 320×320；设置为 320×396。内容按 420px 设计画布等比例显示。顶部模式位于可用区域顶边下 8px，角落模式距右、下各 16px。设置复用同一原生窗口。

## 视觉与动作

浅色纸面、石墨手绘数字、霞鹜文楷中文和橙色按钮；深色为炭灰底。手绘 0–9 与冒号按真实计时组合，语义文字保留给辅助功能。日常页显示剩余分钟、两个操作和本轮使用量；近七天摘要可从页脚悬停说明查看。

胖雀在日常、休息和归来保持同一尺寸、位置与 DOM 节点；入场只淡入，不缩放。日常呼吸眨眼，剩余比例 15%–40% 抬头，最后 15% 缩短抬头间隔，到点招呼。休息放慢呼吸，暂停、离开或系统减弱动态时静止；隐藏停止绘制。

## 流程

首次使用需「开启提醒」。到点提醒不抢键盘焦点；立即休息或推迟 5→8→12 分钟，后续保持 12 分钟，累计使用量保留。关闭或 12 秒未操作同样推迟。

开始休息后显示 mm:ss，8 秒后收起，后台计时继续。可提前结束。休息完成或提前结束会显示归来反馈，即使旧窗口已释放也会重建；6.5 秒后收起，或点「继续做事」立即收起。

设置包含五组：使用时长、休息时长、位置、外观和登录后台运行。合法的自定义旧配置仍可使用。返回、关闭或 Escape 时，未保存的草稿可以继续编辑、不保存离开或保存后离开。

## 使用估计与安静策略

近期键鼠输入、音视频活动及前台切换用于估计使用；只亮屏不维持累计。仅输入宽限支撑的尾段先暂存，后续活动确认后保存；空闲达到十分钟会剔除未确认尾段。超过 15 秒的单次主线程停顿不补计未知使用量。

休息最长连续无输入时间达到设置时长约 80% 才算有效；开始点击有一秒宽限。休息中持续使用电脑会继续累计，未核验通过时不清零。自然离开或已知系统阻塞达到休息时长，也可记为间歇。这些信号不能识别站立或身体姿态。

每日仅在本机记录起来次数、最长连坐和总坐姿时长的估计。跨午夜拆分，定期及退出时保存，重启保留历史。

生产模式日常窗失焦收起，普通隐藏窗口五秒后释放，未保存设置除外。捕获指示出现时收起日常和休息窗；自动提醒及归来在锁屏、捕获或特定全屏静默时等待。信号由公开系统状态提供，不采集按键内容、音频样本或屏幕图像，也不能保证覆盖所有第三方共享程序。

## 看稿模式

`npm run preview:native` 使用独立数据启动同一应用。仅此模式设置 `INTERLUDE_PREVIEW_VISIBLE=1`，窗口置顶，不因失焦或捕获指示收起，便于边聊天边查看；普通运行不启用该开关。

网页预览只模拟系统桥接。真实流程验证运行 `npm run build && npm run test:e2e`，截图和结果在本机 `reports/current/`。
